# Arsal YouTube Live — User Guide

1. In YouTube Studio create/open a live stream and obtain the primary stream key. For dual-format encoder streaming obtain/select the vertical/second key too.
2. Open Arsal YouTube Live and click **Add Video**.
3. Choose **Dual**, **Horizontal Only**, or **Vertical Only**.
4. Paste the appropriate stream key(s). Keys are hidden by default.
5. Check both previews and adjust vertical Fit/Fill, X/Y and Zoom.
6. Keep **Loop video** ON for continuous playback.
7. Run **Pre-flight Check**, then press **START LIVE** and confirm.
8. Use **STOP LIVE** to end transmission.

Remembered keys are protected with Electron safeStorage when available. Very long YouTube broadcasts may have archive/DVR limits, so enable local MKV backup when an archive matters. Dual 1080p30 at the defaults needs strong upload bandwidth.
