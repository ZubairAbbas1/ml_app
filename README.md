# 🚀 Machine Learning Beginner App

A beginner-friendly Machine Learning web app built using Streamlit that allows users to upload a CSV file, automatically detect the supervised problem type, train models, and make predictions.

---

## 📌 Features

- Upload CSV dataset
- Automatic detection (Regression / Classification)
- Data preprocessing (missing values, encoding)
- Multiple ML models:
  - Linear Regression
  - Decision Tree
  - Random Forest
  - XGBoost
  - SVM
  - KNN
  - Logistic Regression
  - Naive Bayes
- Model evaluation:
  - Accuracy, Precision
  - MSE, R² Score
  - Cross-validation
- Prediction system with user input

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- XGBoost
- Pandas
- NumPy
